# :movie_camera: From Visual Flows to Power Programming: The Ballerina Integrator Journey

## WSO2Con Barcelona 2025

In this talk at WSO2Con Barcelona 2025, I walk through the evolution of the Ballerina integrator experience — from visual flow-based development to full-fledged power programming. The session covers how Ballerina bridges the gap between low-code integration tools and general-purpose programming, enabling developers to start with visual flows and seamlessly transition to code when more control is needed.
