In this talk at WSO2Con Barcelona 2025, I walk through the evolution of the Ballerina Integrator experience, from visual flow-based development to full power programming. The session covers how Ballerina bridges low-code integration tools and general-purpose programming, so developers can start with visual flows and move to code when they need more control.
